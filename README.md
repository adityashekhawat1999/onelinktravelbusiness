# One Link Holding

Welcome to the **One Link Holding** repository! This is the primary web platform representing One Link Holding and its subsidiary brands: **One Link Travel** and **CBEST**.

## 🌍 About the Platform

The One Link Holding platform serves as a modern, responsive, and interactive hub for showcasing the company's ecosystem. Built with React and Tailwind CSS, it offers a premium user experience with multi-language support, smooth animations, and optimized performance.

### Brands Included:
- **One Link Holding**: The parent company connecting resources and opportunities.
- **One Link Travel**: Your trusted partner for international visas, travel arrangements, and seamless global mobility.
- **CBEST**: Educational consulting and student placement for fully-funded and selective scholarship programs worldwide.

## ✨ Features

- **Modern UI/UX**: Designed with sleek, premium aesthetics, glassmorphism, and smooth framer-motion animations.
- **Responsive Layout**: Fully optimized for mobile, tablet, and desktop viewing.
- **Multi-language Support**: Dynamic switching between English and Portuguese natively integrated.
- **React Router**: Seamless navigation across different brand pages (Home, Travel, CBEST).
- **Tailwind CSS**: Utility-first styling with custom themes and animations.

## 🚀 Getting Started

To run this project locally, make sure you have Node.js installed, then follow these steps:

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Run the development server:**
   ```bash
   npm run dev
   ```

3. **Build for production:**
   ```bash
   npm run build
   ```
